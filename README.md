# pfSense 防火墙虚拟组网仿真实验
## 实验环境
VMware Workstation，多台虚拟机
拓扑：外网WAN → pfSense防火墙网关 → 内网LAN主机
## 实验内容
1. 接口划分：配置WAN、LAN接口，设置网卡类型
2. NAT配置：开启出站NAT，实现内网主机访问外网
3. 访问控制策略：配置防火墙规则，禁止外网主动发起对内网的访问，放行内网对外访问
4. 安全测试：使用端口扫描工具对外网端口测试，验证防火墙拦截效果，查看流量系统日志
## 问题与排错记录
问题：配置完成后内网无法访问外网
排查：核对WAN口网关信息，NAT规则匹配错误，调整规则后连通恢复
## 收获
熟悉下一代防火墙基础部署流程、策略调试，理解边界网络安全隔离逻辑
